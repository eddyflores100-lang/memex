## Changes in this release

- Rename: fidelis → memex (package `memex-memory`, CLI `memex`).
- AliceLabs hardening: rate limiting, API token auth, audit logging,
  self-healing watchdog.
- Cost-per-query calculator and LongMemEval benchmark runner.
- Docker: `memex` image with MCP-stdio (default) and HTTP entrypoints.
- Environment: canonical `MEMEX_*` env names (legacy `COGITO_*` still
  honored), `MEMEX_RATE_LIMIT_MAX` to tune per-IP limiting.
